# 美甲款式标签体系

## 概述

本标签体系为美甲AI试戴与推荐系统提供标准化的分类标准，涵盖美甲款式的核心维度，支持精准筛选与智能推荐功能。

## 标签维度

### 1. 风格分类 (style)
美甲的整体设计风格，反映美学特征和文化元素。

**枚举值：**
- **经典款** - 传统简约设计，适合日常佩戴
- **法式美甲** - 经典法式边设计，优雅百搭
- **日式美甲** - 日式可爱风，注重细节和立体感
- **韩式美甲** - 韩系清新风格，色彩柔和
- **欧美风** - 大胆前卫，色彩丰富
- **复古风** - 怀旧复古元素，怀旧色调
- **极简风** - 简约线条，少即是多
- **艺术风** - 创意艺术表现，独特设计

### 2. 颜色分类 (color)
美甲的主色调和配色方案。

**主色系：**
- **透明色** - 透明或半透明底色
- **裸色** - 自然肤色系，含裸粉、裸棕、裸灰
- **粉色系** - 粉红、玫瑰粉、豆沙粉、珊瑚粉
- **红色系** - 正红、酒红、樱桃红、砖红
- **橙色系** - 橙色、珊瑚橙、南瓜橙
- **黄色系** - 明黄、柠檬黄、香槟金
- **绿色系** - 薄荷绿、墨绿、橄榄绿、翠绿
- **蓝色系** - 天蓝、宝蓝、深蓝、雾霾蓝

### 3. 场景分类 (scene)
美甲的适用场景和场合。

**日常场景：**
- **日常** - 日常生活佩戴
- **通勤** - 职场办公场合
- **约会** - 约会聚会
- **休闲** - 休闲娱乐

**特殊场合：**
- **婚礼** - 新娘美甲，婚礼场合
- **派对** - 派对聚会，夜生活
- **节日** - 节日庆典
- **度假** - 度假旅游

### 4. 工艺分类 (craft)
美甲的制作工艺和技术特点。

**基础工艺：**
- **纯色** - 单一颜色涂抹
- **渐变** - 颜色渐变过渡
- **法式** - 法式边设计
- **晕染** - 颜色晕染效果
- **大理石** - 大理石纹路
- **水波纹** - 水波纹理

**装饰工艺：**
- **贴纸** - 美甲贴纸装饰
- **手绘** - 手工绘画图案

## 标签使用规则

### 1. 必选标签
每款美甲必须包含以下标签：
- 1个风格标签
- 1-3个场景标签

### 2. 可选标签
根据美甲特点可选择添加：
- 0-3个颜色标签
- 0-2个工艺标签

### 3. 标签优先级
当一款美甲符合多个标签时，按以下优先级选择：
1. **风格** - 选择最突出的主要风格
2. **颜色** - 选择主色调
3. **工艺** - 选择最复杂的工艺为主标签
4. **场景** - 选择最典型的主要场景

### 4. 命名规范
- 标签名称使用中文，简洁明了
- 避免使用主观性过强的词汇
- 同一标签在不同维度下不重复
- 标签名称保持一致性，不使用同义词
